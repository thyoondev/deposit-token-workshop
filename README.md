# 예금토큰 실습 — 수강생 안내

오늘은 연습용 토큰을 **100개 만들고(발행), 20개를 없애서(소각) 80개를 남겨봅니다.** 이후에는 승인된 사람만 토큰을 보낼 수 있게 제한하고, 코드가 의도대로 동작하는지 확인합니다.

완성 코드가 들어 있으므로 빈 파일부터 작성할 필요는 없습니다. 먼저 실행한 뒤 강의에서 설명하는 부분을 읽고 수정합니다. 모든 실습은 내 컴퓨터에서 진행합니다. 실제 돈이나 개인 지갑은 필요하지 않습니다.

## 1. 준비 확인

실습 프로그램을 실행할 [Node.js 24 계열](https://nodejs.org/en/download)과 자료를 내려받을 [Git](https://git-scm.com/downloads/)을 설치합니다. Windows는 PowerShell, macOS는 터미널 앱을 열고 아래 명령을 입력하세요.

```bash
node --version
git --version
```

두 명령에서 버전이 표시되면 다음으로 넘어갑니다. 강의는 **Node.js 24 계열**을 기준으로 진행하며, 24.19.0에서 실행을 확인했습니다. 명령을 찾을 수 없다는 오류가 나오면 설치 후 터미널을 다시 열어주세요.

## 2. 자료 받기

```bash
git clone https://github.com/thyoondev/deposit-token-workshop.git
cd deposit-token-workshop/lab
```

첫 줄은 자료를 내려받고, 둘째 줄은 실습 폴더로 이동합니다. **이후 명령은 모두 이 `lab` 폴더에서 실행합니다.**

## 3. 예제 실행

한 줄이 끝날 때까지 기다린 뒤 다음 줄을 실행하세요. 처음 설치할 때는 인터넷 연결이 필요합니다.

```bash
npm ci
npm run build
npm run demo
```

| 명령 | 하는 일 |
|---|---|
| `npm ci` | 실습에 필요한 프로그램 설치 |
| `npm run build` | 작성된 코드를 실행 가능한 형태로 변환 |
| `npm run demo` | 토큰 발행·소각 예제 실행 |

마지막에 아래 세 줄이 나오면 준비가 끝났습니다.

```text
After mint: 100.0
After burn: 80.0
Supply: 80.0
```

순서대로 **발행 후 잔액 100개**, **소각 후 잔액 80개**, **전체 토큰 수량 80개**라는 뜻입니다.

## 4. 수업 시작

이제 [실습 가이드](lab/실습가이드.md)를 열고 강의 순서대로 진행하세요. 각 단계에 읽을 파일, 실행할 명령, 확인할 결과가 있습니다.

코드가 정상인지 한 번에 확인하려면 다음 명령을 실행합니다.

```bash
npm test
```

완성 코드에서는 `33 passing`이 표시됩니다. 테스트 이름에 `rejects`가 있어도 통과 표시가 나오면 정상입니다. 허용되지 않은 거래가 제대로 거절되는지도 검사하기 때문입니다.

진행이 막히면 [오류 해결 안내](lab/실습가이드.md#오류가-나면)를 확인하세요. 질문할 때는 실행한 명령과 오류 메시지를 함께 보여주세요.
